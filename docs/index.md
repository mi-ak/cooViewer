# coo2 — 快適に漫画を見るために

[紹介](index.md) · [操作マニュアル](manual.md) · [補足情報](other.md) · [開発資料](DEVELOPMENT.md)

coo2 は、漫画や写真集などを読むための macOS 向け画像・コミックアーカイブビューアです。画像の入ったフォルダ、圧縮ファイル、PDF を「本」として開き、単ページや見開きで閲覧できます。

**coo2 は coo 氏による [cooViewer](https://github.com/coo-ona/cooViewer) の派生版で、原作者による公式版ではありません。** このドキュメントは coo2 の操作と対応環境を説明します。

## 対応環境

- Apple Silicon 搭載の Mac（arm64）
- macOS 15 以降
- ソースからビルドする場合はフル版 Xcode

ビルド方法は [README](../README.md#ビルド) を参照してください。

## 開けるファイル

| 種類 | 主な形式 |
| --- | --- |
| 画像・画像フォルダ | JPEG、PNG、GIF、TIFF、BMP、AVIF、WebP など |
| コミックアーカイブ | ZIP／CBZ、RAR／CBR、7z、LHA／LZH など |
| その他のアーカイブ | TAR、gzip、bzip2、XZ、CAB、CPIO、PAX、XAR、ar など |
| PDF | 複数ページ PDF、暗証番号付き PDF |

WebP の静止画像に加え、アニメーション GIF とアニメーション WebP の再生にも対応します。

画像やアーカイブの読み込み可否は、macOS の対応形式や圧縮・暗号化方式によって異なります。パスワード付きアーカイブは、macOS 標準の `libarchive` が復号できる形式を扱います。

## 主な機能

### 好みの読み方でページをめくる

右から左、左から右、各方向の単ページ表示を選べます。画像を画面内に収める、画面の横幅に合わせる、実際のサイズで表示する、見開きを分割して表示する、といった表示方法を切り替えられます。

キーボード、マウス、トラックパッドの操作を割り当てられます。同じ動作に複数のキーを設定し、表示モードごとに操作を変えることもできます。

### 読みたいページをすぐに見つける

サムネイル一覧、ページバー、ページ番号の直接入力で目的のページに移動できます。初期設定では `0`〜`9` キーで全体の 0〜90% の位置へ、`Tab` で 10 ページ先へ移動します。

気に入ったページでは `A` キーでブックマークを追加できます。同じページでもう一度押すと削除します。ブックマークには名前を付けられます。

### 続きから読む

最後に開いた本や各本の読んだ位置、本ごとのページ方向・見開き設定を記憶できます。「最近開いた本」や「最後に開いたページを開く」から再開したり、起動時に前回の本を開いたりできます。

### 表示を調整する

ルーペ、実寸表示、画像の回転、色調整やシャープ化などのフィルターを使えます。背景色、ページ数やページバーの色・位置、サムネイルの行列数も環境設定で変更できます。

### 自動で閲覧する

スライドショーの間隔や、本の最後に到達したときの動作を設定できます。同じフォルダにある別の本への移動にも対応します。

## はじめるには

1. coo2 を起動します。
2. 「ファイル」→「開く...」（`Command+O`）で画像、画像フォルダ、アーカイブ、PDF を選びます。coo2 のアイコンへのドラッグ＆ドロップでも開けます。
3. 初期設定の右から左へ読む場合は、`Space`、`Z`、`←` または画面の左半分のクリックで次のページへ進みます。

詳しくは [操作マニュアル](manual.md) を参照してください。ライセンスや設定ファイルについては [補足情報](other.md) にまとめています。
