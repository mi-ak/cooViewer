## 本を開く

「ファイル」→「開く...」（`Command+O`）で、画像、画像の入ったフォルダ、アーカイブ、PDF を選択します。coo2 のアイコンへのドラッグ＆ドロップでも開けます。このマニュアルでは、これらの閲覧対象を「本」と呼びます。

HEIC の写真は JPEG などに変換せずにそのまま開けます。WebP の静止画像の表示、アニメーション GIF とアニメーション WebP の再生にも対応します。対応環境と主な形式は [紹介](index.md#開けるファイル) を参照してください。

画像ファイルを指定すると、同じフォルダの画像を本として開きます。この場合、同じフォルダの PDF やアーカイブは読み込まないため、それらのパスワード入力は求められません。フォルダ自体を開いた場合は、内部の PDF やアーカイブも読み込みます。

環境設定で「サブフォルダを読み込む」を有効にすると、フォルダ内のサブフォルダも読み込みます。

暗証番号付き PDF や対応するパスワード付きアーカイブを開くと、入力画面が表示されます。正しい暗証番号・パスワードを入力して「OK」を押してください。アーカイブの暗号化方式によっては、macOS 標準の `libarchive` で復号できない場合があります。

## ビューウィンドウ

画像や PDF のページが表示されるメインウィンドウです。

### メニューのショートカット

| 操作 | キー |
| --- | --- |
| 本を開く | `Command+O` |
| 最後に開いた本・ページを開く | `Command+Shift+O` |
| フルスクリーンの切り替え | `Command+F` |
| 画面内に収める | `Command+1` |
| 画面の横幅に合わせる | `Command+2` |
| 画面に合わせない | `Command+3` |
| 見開き分割 | `Command+4` |
| 左に回転 | `Command+5` |
| 右に回転 | `Command+6` |
| フィルターを開く | `Command+Shift+F` |
| ウィンドウをしまう | `Command+M` |
| 本を閉じる | `Esc`、`Command+W` |
| 環境設定を開く | `Command+,` |

ページ番号の入力中は `Esc` で入力を取り消します。

### 表示モード

| モード | 表示方法 |
| --- | --- |
| 画面内に収める（ノーマルモード） | 画像全体が画面内に収まるように拡大・縮小します。 |
| 画面の横幅に合わせる（横幅フィットモード） | 横幅に合わせて拡大・縮小します。縦に長いページはスクロールして読みます。 |
| 画面に合わせない（ノースケールモード） | 画像を拡大・縮小せずに表示します。画面からはみ出す部分はスクロールして読みます。 |
| 見開き分割 | 見開きの片側ずつを横幅に合わせて表示し、スクロールとページ移動で読み進めます。 |

ノーマルモードの拡大率は、環境設定の「最大拡大率」で制限できます。

### ノーマルモードのキー操作

次の表は「右から左」のページ方向を基準にしています。初期設定では、`Z`／`X` と `←`／`→`、およびそれらの `Shift`・`Option` 付き操作は、「左から右」にすると前後が逆になります。`Space`／`Shift+Space` はページ方向にかかわらず次／前のページへ進みます。

| 操作 | キー |
| --- | --- |
| 次のページへ | `Z`、`←`、`Space` |
| 前のページへ | `X`、`→`、`Shift+Space` |
| 1 ページだけ次へ（見開きをずらす） | `Shift+Z`、`Shift+←` |
| 1 ページだけ前へ（見開きをずらす） | `Shift+X`、`Shift+→` |
| 10 ページ進む | `Tab` |
| 10 ページ戻る | `Shift+Tab` |
| 全体の 0〜90% の位置へ | `0`〜`9` |
| ページ番号を入力して移動 | `Return`、テンキーの `Enter` |
| 最初のページへ | `Option+X`、`Option+→` |
| 最後のページへ | `Option+Z`、`Option+←` |
| 次のブックマークへ | `C`、`↓` |
| 前のブックマークへ | `D`、`↑` |
| 現在のページのブックマークを追加／削除 | `A` |
| 左の画像を実寸表示 | `Q` |
| 右の画像を実寸表示 | `W` |
| サムネイル一覧を表示 | `T` |
| 単ページ／見開きの切り替え | `S` |
| ページ数の表示切り替え | `P` |
| ページバーの表示切り替え | `O` |
| スライドショーの開始／停止 | `G` |
| ページ方向の切り替え | `R` |
| ルーペの表示切り替え | `L` |
| 次の本へ | `Control+C`、`Control+↓` |
| 前の本へ | `Control+D`、`Control+↑` |
| 次のサブフォルダ・アーカイブへ | `Control+Shift+C`、`Control+Shift+↓` |
| 前のサブフォルダ・アーカイブへ | `Control+Shift+D`、`Control+Shift+↑` |

キー名のアルファベットは見やすさのため大文字で表記しています。`Shift` の記載がない操作で `Shift` を押す必要はありません。

`Tab` の移動ページ数はキー設定で変更できます。ページ番号を直接指定するには、`Return` を押して数字を入力し、もう一度 `Return` を押します。`Delete` で 1 桁消し、`Esc` で取り消します。

`R` は「右から左」→「左から右」→「右から左（単ページ）」→「左から右（単ページ）」の順に切り替えます。次／前の本へのキー操作は、ループ設定にかかわらず移動先の最初のページを開きます。

### スクロールするモードのキー操作

横幅フィットモードでは次の設定がノーマルモードより優先されます。ノースケールモードと見開き分割では、同じ操作に加えて左右の矢印キーで横にスクロールできます。それ以外のキーはノーマルモードの設定を引き継ぎます。

| 操作 | キー |
| --- | --- |
| 1 画面分下へ、ページ末尾では次のページへ | `Space` |
| 1 画面分上へ、ページ先頭では前のページへ | `Shift+Space` |
| 1 画面分上へ | `Page Up` |
| 1 画面分下へ | `Page Down` |
| ページの先頭へスクロール | `Home` |
| ページの末尾へスクロール | `End` |
| 上へスクロール | `↑` |
| 下へスクロール | `↓` |
| 左へスクロール（ノースケール・見開き分割） | `←` |
| 右へスクロール（ノースケール・見開き分割） | `→` |

ページが横にもはみ出している場合、`Space` は下端まで進んだ後に横へ移動し、次の領域を上から表示します。`Shift+Space` は逆方向に移動します。

### マウス操作

| 操作 | 右から左 | 左から右 |
| --- | --- | --- |
| 次のページへ | 画面の左半分をクリック | 画面の右半分をクリック |
| 前のページへ | 画面の右半分をクリック | 画面の左半分をクリック |
| 1 ページだけ次へ | `Shift` を押して左半分をクリック | `Shift` を押して右半分をクリック |
| 1 ページだけ前へ | `Shift` を押して右半分をクリック | `Shift` を押して左半分をクリック |

| 共通の操作 | 方法 |
| --- | --- |
| ページを飛ばす | ページバーの任意の場所をクリック |
| メニューバーを表示 | フルスクリーン中に画面上部へポインタを移動 |
| コンテクストメニューを表示 | 右クリック、または `Control` を押してクリック |
| 次／前のページへ | ホイールを下／上へ回す（ノーマルモード） |
| ルーペの表示切り替え | ホイールボタンなどの中央ボタンをクリック |

スクロールするモードでは、ドラッグで画像を移動できます。通常のクリックは画面の左右とページ方向に応じて「1 画面分上／下へ＋前／次のページへ」として動作します。ホイールの動作は環境設定の「入力」→「スクロールできるとき」で変更できます。

ポインタは操作しないと自動で隠れ、マウスを動かすと再び表示されます。

### トラックパッドの操作

| 操作 | 初期設定の動作 |
| --- | --- |
| 左／右へのスワイプ | 次／前のページへ。「左から右」では逆になります。 |
| 下／上へのスワイプ | 次／前の本へ |
| ピンチアウト／ピンチイン | 表示モードを拡大／縮小する方向へ切り替え |
| 右／左への回転ジェスチャー | 画像を右／左へ回転 |

ジェスチャーの割り当てもマウス設定で変更できます。

### メニュー

| メニュー | 主な項目 |
| --- | --- |
| coo2 | 「coo2 について」「環境設定...」「coo2 を終了」。 |
| ファイル | 本を開く、最後に開いたページを開く、最近開いた本、同じフォルダのフォルダ・アーカイブ、本を閉じる。 |
| スライドショウ | スライドショーの開始／停止。 |
| ブックマーク | 保存したページへの移動、ブックマークの編集。 |
| 設定 | ページ方向、ソート、単ページ／見開きの切り替え、現在の本の設定を削除。 |
| 表示 | 表示モード、左右への回転、フィルター。 |
| ウインドウ | フルスクリーンの切り替え、ウィンドウをしまう。 |

「同じフォルダのフォルダ・アーカイブ」には、現在の本と同じフォルダにある本を名前順で表示します。ソートはファイル名・作成日・変更日・シャッフルから選べます。日付情報を使えない本では日付順を選べません。

## 一覧表示画面

`T` キー、またはコンテクストメニューの「一覧を表示」でサムネイル一覧を開きます。

| 操作 | 方法 |
| --- | --- |
| 並び順を変更 | ソートメニューでファイル名・作成日・変更日を選択。メイン画面にも反映します。 |
| 次の一覧へ | 次ページに割り当てたキー、ホイールダウン、次の一覧の矢印ボタン |
| 前の一覧へ | 前ページに割り当てたキー、ホイールアップ、前の一覧の矢印ボタン |
| 1〜10 番目の一覧へ | `0`〜`9` |
| 選んだページへ | サムネイルをクリック |
| 閉じる | `Esc`、`Command+W`、閉じるボタン |

サムネイルの行数・列数や、本を開いたときに一覧を表示するかどうかは環境設定で変更できます。

## 実寸表示ウィンドウ

`Q`／`W` キー、またはコンテクストメニューの「実際のサイズで表示」で、左／右の画像を別ウィンドウに表示します。

| 操作 | 方法 |
| --- | --- |
| 次／前のページへ | 次／前ページに割り当てたキー（初期設定では `Z`／`X`） |
| 下へスクロールし、末尾では次のページへ | `Space` |
| 上へスクロールし、先頭では前のページへ | `Shift+Space` |
| 上下左右へ移動 | 矢印キー、画像上でドラッグ |
| 先頭／末尾へスクロール | `Home`／`End` |
| 1 画面分上／下へ | `Page Up`／`Page Down` |
| 閉じる | `Esc`、`Command+W`、閉じるボタン、背面のウィンドウをクリック |

このウィンドウでは矢印キーはページめくりではなくスクロールに使います。「実寸表示ウィンドウのサイズを内容に合わせる」を有効にすると、ページをめくったときにウィンドウサイズも調整します。

## ブックマークの編集

閲覧中のページで `A` を押すとブックマークを追加し、同じページでもう一度押すと削除します。ブックマークメニューから保存したページを選んで移動できます。

### 現在の本を編集

本を開いているときに「ブックマーク」→「ブックマークを編集...」を選ぶと、編集シートが表示されます。

| 操作 | 方法 |
| --- | --- |
| 名前を変更 | ブックマーク名をダブルクリックして編集 |
| 削除 | ブックマークを選んで `Delete`、またはコンテクストメニューの「このブックマークを削除」 |
| 追加 | 左下の欄にページ番号を入力し、「新しいブックマークを追加」 |

### すべての本を編集

本を開いていないときに「ブックマークを編集...」を選ぶと、全ブックマークの編集ウィンドウが表示されます。

| 操作 | 方法 |
| --- | --- |
| 本を開く | 「本の名前」で選び、ダブルクリックまたは「開く」 |
| 本を Finder に表示 | 「本の名前」で選び、「Finder に表示」 |
| その本のブックマークをすべて削除 | 「本の名前」で選び、`Delete` |
| 個別のブックマークを編集 | 本を選び、名前の変更・削除・ページ番号を指定した追加を行う |

## ルーペとフィルター

`L` キーまたは中央ボタンのクリックでルーペを表示し、ポインタ付近を拡大できます。大きさ・拡大率は環境設定の「アピアランス」で変更できます。

「表示」→「フィルター」（`Command+Shift+F`）で、色調整、色効果、シャープ化、ぼかしなどのフィルターを選択できます。追加したフィルターのパラメーターを調整し、不要になったものは各フィルターの閉じるボタンで削除します。

## 環境設定

「coo2」→「環境設定...」（`Command+,`）で開きます。

### 一般

| 設定 | 内容 |
| --- | --- |
| 標準の本の設定 | ページ方向、単ページ表示、ソート順を設定します。単ページ表示でもページ方向により次／前のクリック位置が変わります。 |
| 単ページ自動判定 | 縦を 1000 ピクセルとしたときの横幅で、単独表示する画像を判定します。 |
| 最大拡大率 | 小さい画像を画面に合わせるときの拡大率の上限を設定します。 |
| スライドショーの間隔 | 自動でページをめくる間隔を 0〜300 秒で設定します。 |
| サブフォルダを読み込む | フォルダ内のサブフォルダも読み込みます。 |
| ループ | 本の先頭・末尾を超えたときに、同じ本をループする、次／前の本へ移動する、何もしない、などを選びます。 |
| 変更された本の設定を記憶する | 本ごとのページ方向、ソート、単ページ／見開き設定を記憶します。 |
| すべての本の最後に開いたページを記憶する | 各本の読んだ位置を保存します。 |
| 本を開いたときに最後に開いたページに移動 | 保存した位置へ移動する際に、常に移動する、尋ねる、移動しない、を選びます。 |
| 最近開いた本の数 | 「最近開いた本」メニューに残す件数を設定します。 |
| 起動時に最後に開いた本を開く | 前回の本を自動的に開くかを設定します。 |

ファイルやアーカイブを指定して起動した場合は、指定した本を直接開きます。「起動時に最後に開いた本を開く」は、ファイルを指定せずに起動した場合だけ適用されます。

「最後に開いたページを開く」や「最近開いた本」から開いた場合は、保存した読書位置へ移動します。

### アピアランス

背景色、ページ数表示の位置・フォント・文字色・背景色・枠、ページバーの位置・サイズ・色・既読部分・サムネイル表示を調整できます。ページ数やページバーの表示・自動非表示、ルーペの大きさ・拡大率も設定できます。

一覧表示の行数・列数や、本を開いたときに一覧を表示するかどうかも、このタブで設定します。「実寸表示ウィンドウのサイズを内容に合わせる」もここにあります。

### 入力

キーボードとマウスの割り当ては、それぞれのタブで変更します。表示モードごとに設定できます。

| 設定 | 内容 |
| --- | --- |
| 前のページへ戻ったときの動作 | 「1 画面分上へ＋前のページへ」で前のページへ戻る際、先頭から表示するか末尾から表示するかを選びます。 |
| 感度 | マウスホイールの感度を調整します。 |
| スクロールできるとき | ホイールで通常のスクロール、横の領域への移動を含むスクロール、スクロール＋ページめくり、ページめくりのみ、を選びます。 |

「ノーマルスクロール」では上下にスクロールし、`Shift` を押すと左右にスクロールします。

### 高度な設定

| 設定 | 内容 |
| --- | --- |
| 先読みモード | `Old`／`New` を選択します。画面の注記のとおり、`Old` は Retina ディスプレイでは正常に動作しません。 |
| 画像拡大縮小時の補間設定 | 拡大・縮小時のなめらかさを設定します。 |
| キャッシュ | 画像、画面、サムネイルのキャッシュ量を設定します。 |
| CALayer を使用 | GPU を使う描画を選択します。表示がぼやける場合は切り替えて確認できます。 |
| PDF 内リンクをデフォルトブラウザで開く | 常に開く、尋ねる、開かない、を選びます。 |
| 本が移動された場合のカレントフォルダ変更 | 現在開いている本が移動したときの扱いを選びます。 |
| 設定の整理 | 保存済みの本の設定や履歴を整理します。 |

## キー設定の仕方

1. 環境設定の「入力」→「キーボード」を開きます。
2. 表の下のモード選択で、設定する表示モードを選びます。
3. 「追加...」を押し、必要なら `Shift`／`Option`／`Control` を押しながら登録したいキーを押します。
4. 動作メニューから、割り当てたい操作を選びます。
5. 「指定ページ進む」「上へスクロール」などの値を指定できる動作では、隣の欄に移動量を入力します。
6. ページ方向によって前後を逆にしたい場合は、「ページ方向が“左から右”のとき、逆の動作に変化させる」を選びます。
7. 「OK」で追加します。

削除するには行を選んで「削除」を押します。「リセット...」で初期設定に戻せます。同じキーの重複登録は自動で検出されないため、表で割り当てを確認してください。

ノーマルモードの設定が基本です。他のモードに同じキーの設定がある場合は、そのモードの設定を優先します。たとえば、ノーマルモードに `Space`＝「次のページ」、横幅フィットモードに `Space`＝「1 画面分下へ＋次のページ」を登録すると、モードによって動作が変わります。

見開き分割は「画面に合わせない」モードの入力設定を使います。coo2 は Apple Remote の入力に対応していません。

## マウス設定の仕方

1. 環境設定の「入力」→「マウス」を開きます。
2. 表の下のモード選択で、設定する表示モードを選びます。
3. 「追加...」を押し、動作メニューから割り当てる操作を選びます。
4. 必要な修飾キーを選び、ボタンやジェスチャーを指定します。ボタン操作ではクリック・ドラッグなどの種類も選びます。
5. 必要な移動量や、ページ方向による動作の反転を設定します。
6. 「OK」で追加します。

一般的な 3 ボタンマウスでは `button0` が左、`button1` が右、`button2` が中央ボタンです。スワイプ、ピンチ、回転ジェスチャーも選択できます。

削除するには行を選んで「削除」を押します。「リセット...」で初期設定に戻せます。同じ組み合わせを重複させないよう確認してください。モード別設定の優先順位はキー設定と同じです。

## 割り当てられる動作

### ページ・本・ブックマーク

| 動作 | 内容 |
| --- | --- |
| 次／前のページへ | 見開きでは表示単位でページをめくります。 |
| 1 ページだけ次／前へ | 見開きを 1 ページずらします。例：3〜4 ページ→4〜5 ページ。 |
| 最初／最後のページへ | 本の先頭／末尾へ移動します。 |
| 指定ページ進む／戻る | 設定したページ数だけ移動します。初期設定の `Tab` は 10 ページです。 |
| 指定ページへ | キーを押してページ番号を入力し、同じキーで確定します。 |
| % ページへ | 指定した割合の位置へ移動します。 |
| 次／前のブックマークへ | 現在位置より後／前にある最寄りのブックマークへ移動します。 |
| ブックマークを追加／削除 | 現在のページのブックマークを切り替えます。 |
| 次／前のフォルダ・アーカイブへ | 同じフォルダの名前順で次／前の本を、最初のページから開きます。 |
| 次／前のサブフォルダ・アーカイブへ | 読み込んだ本の内部にあるサブフォルダ・アーカイブの境界へ移動します。 |
| 最後に開いたページを開く | 前回の本・ページを開きます。 |
| スライドショウ | 設定した間隔で自動的にページをめくります。 |

### 表示・本の設定

| 動作 | 内容 |
| --- | --- |
| 一覧を表示 | サムネイル一覧を開きます。 |
| 左／右の画像を実際のサイズで表示 | 読む方向にかかわらず、画面の左／右にある画像を実寸表示します。 |
| 左／右の画像を Finder に表示 | 画像の場所を表示します。アーカイブ内の画像ではアーカイブファイルを表示します。 |
| 左／右の画像をゴミ箱に移動 | 対象の画像をゴミ箱に移動します。アーカイブ内の画像では本全体が対象になります。 |
| 単ページ／見開きを切り替え | 現在のページの組み合わせを変更します。 |
| ページ方向を切り替え | 左右のページ方向と単ページ表示を順に切り替えます。 |
| ソートモードを切り替え／シャッフル | 本の画像の並び順を変更します。 |
| ページ数／ページバーを表示 | ページ情報や、読書位置を示すバーを表示・非表示にします。 |
| ルーペを表示／ルーペ拡大率を変更 | ポインタ付近を拡大し、倍率を調整します。 |
| 左／右に回転 | 表示する画像を回転します。 |
| 表示モードを切り替え | 画面内→横幅→見開き分割→拡大・縮小なしの順に切り替えます。 |
| 表示モードを拡大／縮小 | 同じ順序で一段ずつ進める／戻します。 |
| フルスクリーン／ウィンドウをしまう／閉じる | ウィンドウを操作します。 |

本の設定を記憶するオプションが有効なら、変更したページ方向や見開き設定などを次回も使えます。

### スクロール

| 動作 | 内容 |
| --- | --- |
| 1 画面分上／下へ | 画面単位でスクロールします。 |
| 1 画面分上／下へ＋前／次のページへ | 上下に進み、必要なら横の領域へ移り、ページの先頭・末尾に達するとページをめくります。 |
| 最初／最後へスクロール | ページの先頭／末尾へ移動します。左右の位置はページ方向に従います。 |
| 上下左右へスクロール | 設定した量だけ移動します。初期設定の矢印キーは 20 です。 |
| ドラッグスクロール（マウスのみ） | ボタンを押したまま画像を動かします。ドラッグ操作に割り当てます。 |

### マウス専用の動作

「次／前のページへ」「1 ページだけ次／前へ」「最後／最初のページへ」「次／前のブックマークへ」「次／前のフォルダ・アーカイブへ」などは、画面の左右どちらで操作するかに応じて動作を選びます。ページめくりなどの前後関係はページ方向にも従います。

「左／右の画像を実際のサイズで表示」「左／右の画像を Finder に表示」「左／右の画像をゴミ箱に移動」「左／右に回転」では、操作した側を対象にできます。「コンテクストメニュー」をボタンに割り当てることもできます。
